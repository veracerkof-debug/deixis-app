# Ночные проверки Deixis (10 прогонов)

Каждый прогон — дотошный проход по своей части приложения до мелочей, плюс исследование открытых проектов
и алгоритмов для этой части. Найденное:

- ошибка, «дичь», неудобство → исправить сразу, проверить тестами (core/desktop локально, Android — CI), закоммитить;
- открытое решение с совместимой лицензией (Apache-2.0, MIT, BSD, MPL-2.0, LGPL; GPL-3.0 — тоже, проект GPL-3.0-or-later),
  которое точно подходит и встаёт без риска → встроить сразу (свой код по описанию алгоритма, библиотеки — только
  совместимые; чужой код приложений не копировать — CLAUDE.md);
- сомнительное, крупное, меняющее устройство или требующее решения автора → записать в REPORT.md.

Жёсткие правила CLAUDE.md — всегда: на вывод в зал не попадает интерфейс; сбой пульта не трогает вывод;
цвета/размеры/анимации из токенов; строки RU/UZ/EN; без рекламы, аналитики, трекеров; новый жест — в DESIGN.md;
значимое решение — в DECISIONS.md.

## Прогоны

1. Телефон: главный экран, предпросмотр/зал, сетлисты, библиотека, добавление файлов, передача на экраны, темы, слои поверх.
2. Телефон: Библия и модули MyBible, поиск, адреса; Holyrics (оба режима), перенос, права токена.
3. Ядро: протокол, приёмник, ретранслятор, зрители, пары/PIN, безопасность сети, восстановление связи.
4. Компьютер: окна вывода, мониторы, VLC-видео, PPTX/DOCX → PDF, обновления, трей, QR Holyrics.
5. ТВ и «Стать экраном», HDMI/второй экран, DLNA, Cast, уход с экранов, логотип.
6. Веб-пульт и веб-версия (демо): все экраны, жесты, iPhone/Safari, офлайн.
7. Профили, автокопии, восстановление, перенос старых данных, порча файлов, обновление версий.
8. Дизайн и доступность: токены, контраст, размеры касаний, чтение экрана, переводы RU/UZ/EN.
9. Скорость, память, батарея, большие файлы, длинные списки, сеть с потерями.
10. Сборки, CI, выпуск, обновления, лицензии, документация; финальный общий проход.

После 10-го — выпуск (если CI зелёный) и итоговое сообщение автору с отчётом из REPORT.md.
