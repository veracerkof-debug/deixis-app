# Отчёт ночных проверок

Формат: что найдено → что сделано (коммит) или предложение на решение автора.

## Исправлено и встроено

### Прогон 1 — главный экран телефона (сетлисты, предпросмотр/зал, библиотека, темы, слои)
- Падение: одна песня дважды в плейлисте Holyrics → дубль ключа строки на главном. Плейлист переносится без повторов, сетлист на главном показывается без дублей.
- Падение: листание предпросмотра у элемента без слайдов (пустой текст, место Библии без модуля).
- Писание в демо-сетлисте на первом запуске оставалось пустым до перезапуска: пустой результат больше не запоминается, пока модули Библии грузятся.
- «Убрать демо» удаляло свои песни и сетлисты с такими же названиями («Amazing Grace», «Объявления», «Демо») — теперь только демо-элементы (метка или совпадение содержимого); общие демо-файлы не стираются, пока есть другие профили; «Вернуть демо» не трогает свой пустой сетлист.
- Смена профиля во время показа: «Дальше» по презентации из прежнего профиля ничего не отправлял, песня меняла оформление посреди показа, слои поверх прежнего профиля нельзя было убрать — то, что в зале, теперь уходит вместе с оператором.
- Удаление элемента, который в предпросмотре/в зале: предпросмотр закрывается, показ в зале продолжается; уходят его оформление и следы (хэши, переводы).
- Отсчёт «дальше» не из сетлиста запускал в зал первый элемент сетлиста.
- «Заглавные» в своей теме не доходили до зала.
- «В зал» с правкой оформления на миг повторно отправлял прежний слайд (мигание, перезапуск видео).
- Сохранение темы из панели тем молча готовило её в зал со следующим «В зал».
- Файл, добавляемый во время смены профиля, попадал в другой профиль.
- «В сетлист» без выбранного сетлиста говорил «добавлено», но ничего не делал — теперь берётся сетлист на главном или создаётся «Сегодня».
- Числа вместо токенов (скорость значков связи, затемнение, цвета полноэкранного просмотра) — в токены.
- Встроено: импорт песен из открытых форматов ChordPro и OpenLyrics (свой разбор по спецификациям, без XXE) — через «Файл».

## На решение автора (сомнительное, крупное)

### Из прогона 1
- Один размер текста на всю песню (как в Quelea): слайды не «прыгают» размером. Меняет вид всех песен — нужно ваше «да».
- Автолистание объявлений по кругу (каждые N секунд) для своих текстов, как у FreeShow/Holyrics.
- Вид «Сцена» с выбираемой раскладкой (текущий, следующий, часы, таймер, заметки) — сейчас раскладка одна.
- Повторы одной песни в сетлисте (реприза в конце): сейчас сетлист хранит элемент один раз; чтобы разрешить повторы, нужна перестройка порядка и ключей.
- Запись хэшей/фонов, которые досчитываются после смены профиля, в прежний профиль (сейчас — в открытый; редкий случай).

## Открытые проекты и алгоритмы, изученные по ходу

- FreeShow (GPL-3.0): раскладки «Сцены», таймеры слайдов, очистка по слоям. Идеи, без кода.
- OpenLP (GPL-3.0-or-later): поиск по первой строке, порядок куплетов «V1 C V2 C», заметки к пунктам служения.
- Quelea (GPL-3.0): свой Android-пульт, импорт многих форматов, один размер на песню.
- OpenLyrics (открытый XML, без файла лицензии — разбор свой по спецификации), ChordPro (спецификация chordpro.org) — встроено.
- Подбор размера текста: Android StaticLayout HIGH_QUALITY (Минкин, близко к Кнуту–Пласcу); на JVM — свой Кнут–Пласс + двоичный поиск по размеру.
- Дубли фото: JImageHash (MIT) или свой dHash/pHash.
- Видео по сети: OMT (MIT, без Java-привязок), SRT (MPL-2.0), WebRTC (BSD-3) — для зрителей в браузере.
