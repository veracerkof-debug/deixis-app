# Словарь Deixis

Слова интерфейса и документов → что это в коде. Порядок — по смыслу.

| Термин | Что это | В коде |
|---|---|---|
| Пульт | Интерфейс оператора: телефон, окно на компьютере, веб-пульт в браузере | `pult/` (`Controller`, `DeixisPhone`), `core/…/web/remote.html` |
| Экран, приёмник | Устройство, которое показывает: ТВ, проектор, компьютер, телефон в режиме «Стать экраном» | `ReceiverCore`, `ReceiverServer` (core), `ReceiverApp` (desktop), `ReceiverRuntime` (android/receiver) |
| Зал | Картинка для зрителей на мониторе или ТВ; раскладка `HALL` | `OutputLayout.HALL`, `OutputWindow` |
| Вывод | Куда экран выводит показ: мониторы компьютера с раскладками, экраны в сети, экран в браузере | `Outputs.kt`, `OutputsHost`, «Устройства» → «Выходы» |
| Вход | Откуда ещё картинка приходит на экран: монитор, окно программы, виртуальный экран, AirPlay | `CaptureHost`, `CaptureSource`, «Устройства» → «Входы» |
| Раскладка | Что показывает монитор: Зал, Сцена, Титры, Хромакей, Наложение | `OutputLayout` |
| Сцена | Монитор ведущего: текущий и следующий слайд, часы | `OutputLayout.STAGE`, `OutputFrames.stage` |
| Титры | Текст и Писание внизу на чёрном | `OutputLayout.LOWER_THIRD`, `captionContent` |
| Хромакей | Текст на зелёном — для OBS/vMix | `OutputLayout.CHROMA` |
| Наложение | Прозрачное окно поверх того, что на мониторе: слой своей плотности и элементы показа | `OutputLayout.OVERLAY`, `WindowMode.OVERLAY`, `MonitorOutput.dim`, `ClickThrough` |
| Слой (поверх показа) | Логотип, плашка, бегущая строка, часы — поверх слайда | `Overlays` (core), `OverlayPainter` (desktop), `OverlayLayer` (android) |
| Предпросмотр / «В зал» | Слайд, подготовленный к показу, и отправка его в зал | `Controller.preview`, `previewToLive`, `Cue` |
| Сетлист | Порядок элементов на служение или мероприятие | `Setlist` (`Model.kt`) |
| Библиотека | Все элементы пульта: песни, тексты, Библия, фото, видео, презентации, файлы, отсчёты | `StoreData.items`, `LibItem`, `Kind` |
| Тема | Оформление текста слайда | `TextStyle`, `Themes.kt` |
| Профиль | Отдельная библиотека и настройки на одном пульте | `Profiles.kt` |
| «Чёрный», «Логотип», «Очистить», «Уйти» | Режимы зала | `Mode.BLACK`, `LOGO`, `CLEAR`, `AWAY` |
| Сопряжение, PIN | Первый вход пульта на экран; после — постоянный токен | `Pairing`, `PairingCode`, `/ws` `Hello` |
| Подтверждение подключения | Новое устройство с верным PIN ждёт «Разрешить» | `Peers`, `ConnectRequest`, `ApprovalWindow` |
| «QR и код на экран» | Заставка с QR и PIN поверх показа по кнопке оператора | `ReceiverState.connectCard`, `/api/connect-card`, `ConnectCodesSheet` |
| Шифрованный вход | TLS-порт экрана с самоподписанным сертификатом и проверкой отпечатка | `TlsGateway`, `TlsIdentity`, `PinnedTrustManager` |
| «Этот компьютер» | Пульт компьютера, связанный со своим экраном по 127.0.0.1 | `Target.Kind.LOCAL`, `operator-token`, `SenderClient.sameDevice` |
| Роль компьютера | Пульт / Экран / Пульт и экран | `Role` (`RoleChooser.kt`) |
| Виртуальный монитор (экран) | Свой дополнительный монитор Deixis: туда уходит зал или любая программа для ретрансляции | `VirtualScreen` и реализации по системам, `windows-display/` |
| Ретрансляция | Экран показывает картинку другого монитора или программы и передаёт её дальше: в зал, зрителям, на экраны в сети | `DesktopCapture`, `ScreenCapture`, `ScreenRelay` |
| Зрители | Смотрят показ в браузере по QR, без приложения | `Viewer.kt`, `/view` (см. PROTOCOL.md) |
| Веб-пульт | Пульт в браузере (iPhone, чужой компьютер) | `WebRemote.kt`, `remote.html` |
| «Стать экраном» | Телефон сам становится экраном | `ScreenActivity` (android/phone) |
| Кабель, Миракаст | Второй дисплей телефона (HDMI, беспроводной) | `HdmiOutput`, `Target.Kind.CABLE/MIRACAST` |
| DLNA | Открытые беспроводные экраны (запасной путь) | `Dlna.kt`, `DlnaOutput` |
| Holyrics | Внешняя программа для церквей: пульт и мост к ней | `Holyrics*.kt` |
| Диагностика, журнал | Проверки устройства и экранов, log.txt | модуль `diag`, `DiagnosticsSheet` |
| Плотность слоя | Насколько затемнён полупрозрачный слой «Наложения», 0–100 % | `MonitorOutput.dim`, `overlayAlpha` |
