# Презентер для Android

Презентер для церквей, конференций, школ и залов, который целиком работает на Android-телефоне. Две части: пульт оператора на телефоне и веб-приёмник для ТВ, приставок и браузера.

## Обязательно перед работой

- Дизайн-код: [DESIGN.md](DESIGN.md). Каждый новый экран проверяется его четырьмя принципами и шестью свойствами.
- Журнал решений: [DECISIONS.md](DECISIONS.md). Значимое решение записывается туда строкой.

## Жёсткие правила

- На вывод в зал никогда не попадает интерфейс: тосты, ошибки, курсор, системные панели.
- Сбой пульта не трогает вывод. При невозможности показать новый слайд остаётся прежний или чёрный.
- Цвета, размеры и анимации интерфейса берутся только из токенов, без чисел в коде.
- Все строки идут через систему переводов: русский (основной), узбекский латиницей, английский. Без обращения на «ты» и «вы».
- Без рекламы, аналитики и трекеров. Сеть только по действию оператора.
- Новый жест добавляется в карту жестов в DESIGN.md.
- Чужой код приложений не копируется. Библиотеки подключаются только с лицензией, совместимой с лицензией проекта.
