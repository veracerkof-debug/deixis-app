# Deixis

Deixis (греч. δεῖξις — «показ», от δείκνυμι — «показывать») — светское приложение для показа презентаций, слайдов, видео, фото и текста на любом экране: Android TV, мобильный проектор, интерактивная доска, компьютер. Телефон — пульт и дублёр показа; файл воспроизводит экран, на который его отправили. Зрители по QR-коду смотрят трансляцию в браузере. Церковные функции (Библия MyBible, позже песни и сетлисты) — дополнительный раздел «Ещё», не основа. Три приложения: Deixis (универсальная версия: пульт и экран на любом Android), Deixis TV (облегчённая: только экран), Deixis для компьютера.

## Жёсткие правила

- На вывод в зал никогда не попадает интерфейс: тосты, ошибки, курсор, системные панели.
- Сбой пульта не трогает вывод. При невозможности показать новый слайд остаётся прежний или чёрный.
- Цвета, размеры и анимации интерфейса берутся только из токенов, без чисел в коде.
- Все строки идут через систему переводов: русский (основной), узбекский латиницей, английский. Без обращения на «ты» и «вы».
- Без рекламы, аналитики и трекеров. Сеть только по действию оператора.
- Новый жест добавляется в карту жестов в DESIGN.md.
- Чужой код приложений не копируется. Исключение по решению автора — приём AirPlay, переписанный на Kotlin по UxPlay (GPL-3.0, части из RPiPlay и shairplay под LGPL-2.1+, playfair под GPL-3.0): происхождение — в шапках файлов `core/.../airplay/` и в `NOTICE`; в сборку для Google Play он не входит. Лицензия проекта — GPL-3.0-or-later (`LICENSE`, `NOTICE`). Библиотеки подключаются только с совместимой лицензией: Apache-2.0, MIT, BSD, MPL-2.0, LGPL. Закрытые SDK — только Google Cast, Google Play services и NDI по исключению в `NOTICE`, и только в варианте сборки для Google Play.
